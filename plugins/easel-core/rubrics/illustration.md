# Illustration rubric

Shared scale and rules: [README](README.md). Score each dimension 1-10.

| Dimension | What a 7 looks like |
|---|---|
| **Idea** | The image says one thing; for concept illustrations the metaphor survives the removal test (take the caption away and it still reads) |
| **Silhouette and readability** | Main shapes read in black fill; the subject is clear at thumbnail size |
| **Drawing quality** | Consistent stroke logic, clean joins, believable construction, no stray points |
| **Light and form** | One light direction; values separate planes; shading uses hue shifts, not only darker copies |
| **Colour** | Limited, purposeful palette; one dominant hue; no unearned blue-purple |
| **Consistency** | A recurring character or mascot keeps its proportions and features across images |
| **Technical** | Valid, compact SVG (no huge path dumps when a shape would do); `viewBox` set; accessible title when used in UI |
