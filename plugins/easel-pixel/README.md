# easel-pixel

Optional pixel-art add-on that drives Aseprite through an MCP bridge: draw, shade, animate and
export sprites.

**Status:** skeleton (v0.0.1). Nothing to use yet; see [the roadmap](../../docs/roadmap.md).

**Requires:** `easel-core` (installed automatically as a dependency) and Aseprite, which is a paid
app you install yourself.

Easel is not affiliated with, endorsed by or sponsored by Aseprite or Igara Studio.

## Install

```text
/plugin install easel-pixel --marketplace Sh0aib-Ja0allah/easel
```

On Claude Code older than 2.1.275, add the marketplace first:
`/plugin marketplace add Sh0aib-Ja0allah/easel`, then `/plugin install easel-pixel@easel`.
