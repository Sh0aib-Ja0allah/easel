# easel-ai-media

Generative images, video and voice through one provider layer. You bring your own API keys; every
job shows a cost estimate before it spends anything. Voice cloning requires a recorded consent
statement from the voice owner.

**Status:** skeleton (v0.0.1). Nothing to use yet; see [the roadmap](../../docs/roadmap.md).

**Requires:** `easel-core` (installed automatically as a dependency) and your own provider key(s).

## Install

```text
/plugin install easel-ai-media --marketplace Sh0aib-Ja0allah/easel
```

On Claude Code older than 2.1.275, add the marketplace first:
`/plugin marketplace add Sh0aib-Ja0allah/easel`, then `/plugin install easel-ai-media@easel`.
