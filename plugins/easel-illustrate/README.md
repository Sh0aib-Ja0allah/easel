# easel-illustrate

Still illustration and drawing: SVG for UI, SVG illustration and characters, concept
illustration with a mascot you supply, and generative art.

**Status:** skeleton (v0.0.1). Nothing to use yet; see [the roadmap](../../docs/roadmap.md).

**Requires:** `easel-core` (installed automatically as a dependency).

## Install

```text
/plugin install easel-illustrate --marketplace Sh0aib-Ja0allah/easel
```

On Claude Code older than 2.1.275, add the marketplace first:
`/plugin marketplace add Sh0aib-Ja0allah/easel`, then `/plugin install easel-illustrate@easel`.
