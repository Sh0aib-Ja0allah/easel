How a request reaches the doorstep

Median: days, request to delivery

01 Day 0

Request

A reader phones any branch or uses the catalogue’s “Deliver to me” button.

02 Day 1

Pick

Branch staff pull the title the next morning and bag it with a returns label.

03 Day 2–3

Deliver

A volunteer driver brings it on the fixed weekly route for that village.

04 Week 3

Return

The same driver collects finished books on a later visit. No fines.
