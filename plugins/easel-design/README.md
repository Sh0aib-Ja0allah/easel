# easel-design

Graphic, UI and brand design: social graphics, posters, ads, infographics, decks, UI screens,
landing pages, generic design systems, brand identity, logos, icons and design directions.

**Status:** skeleton (v0.0.1). Nothing to use yet; see [the roadmap](../../docs/roadmap.md).

**Requires:** `easel-core` (installed automatically as a dependency).

## Install

```text
/plugin install easel-design --marketplace Sh0aib-Ja0allah/easel
```

On Claude Code older than 2.1.275, add the marketplace first:
`/plugin marketplace add Sh0aib-Ja0allah/easel`, then `/plugin install easel-design@easel`.
